Reference

Colour is the fractional part of the value. A point (x, y) is painted by z, so the classic views answer "which z solves z op y = x?"

Variables x, y, r (radius), a (angle), t (time). Any other bare name becomes a free variable with its own slider.

Constants pi, tau, e, phi

Operators + − * / % ^ and postfix !  ·  juxtaposition multiplies: 2x, 3(x+y)

Calculus deriv(u, x, sin(u)) · deriv2(u, x, u^3) · integ(u, 0, x, u^2). Numerical, so the index is a bound name like the one a sum takes.

Zeta zeta(s) and eta(s) are real on the real line. To see the critical strip, read the point as s = x + iy and draw a real part of it: zetare, zetaim, zetaabs or zetaarg.
